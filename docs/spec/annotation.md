# 数据标注规格

数据标注页为顶部主导航中的独立页面，不隶属于“数据处理”子菜单。

当前数据标注页约定：

- 其他页面修改项目共享图片目录或 Labelme 标注目录后，数据标注页应立即重新读取对应路径并刷新当前图片与列表；YOLO 标注目录继续与数据集划分页共用，不与图片压缩目录关联。

- 左侧工具栏包含：`图片文件夹`、`标签文件夹`、`上一张`、`下一张`、`画标注框`、`AI预标注`、`更多设置`。
- `标签文件夹` 当前指 Labelme `.json` 标注目录；默认保存与读取 Labelme `.json`。
- `YOLO` 标注目录不再作为左侧独立按钮显示，而是在“更多设置”中配置；项目目录内显示为相对路径，确认保存时解析为实际项目路径；开启自动转换后，同步写入 YOLO `.txt` 标注。
- 右侧配置区包含：`任务类别`、`标注类别`、`管理类别`、当前图片标注列表、图片列表。
- `任务类别` 当前为 `detect` / `obb`，决定保存标签时的最终输出格式。
- `标注类别` 为当前新建标注默认使用的类别；右键菜单也支持修改已选中标注的类别。
- 右键菜单顶部必须包含 `编辑` 模式；仅在 `编辑` 模式下允许直接选中、拖动、编辑已有标注。
- 当前支持的绘制模式包括：
  - `矩形框`
  - `圆形`
  - `镜像有向矩形`
  - `有向矩形`
  - `多边形`
  - `直线扩展`（默认关闭，仅在“更多设置”中开启后显示）
- `镜像有向矩形`：先确定一条中心线，再向两侧同时扩展矩形。
- `有向矩形`：先确定一条边线，再向单侧扩展矩形。
- `直线扩展`：以线段为中心线，按固定像素向左右扩展成 OBB；默认扩展像素为 `10`。
- 点击左侧 `画标注框` 按钮时，应先弹出标注类型选择窗口；`编辑` 与下方各绘制类型共用一个连续外框，中间使用固定 `2 px` 高的较粗分隔线隔开。
- 标注类型选择窗口默认宽度为 `240 px`，SAM 标题行距窗口顶部 `12 px`；在形状列表上方提供 SAM 图标、`44 x 24 px` 椭圆动画开关，以及同一行的模型下拉框和约 `50 x 36 px` 的紧凑`高级`按钮；按钮文字左右保留 `8 px` 内边距，模型名称过长时允许下拉框横向压缩并省略显示；开关使用绿色开启轨道、灰色关闭轨道、白色滑块及约 `140 ms` 平移动画，并支持鼠标、空格键、焦点和禁用状态。
- SAM 模型从当前项目与程序根目录的 `data/models/*.pt` 扫描，当前项目中的同名文件优先；所有文件名以 `sam`（不区分大小写）开头的 checkpoint 都纳入列表。官方 SAM 2/2.1 的 Tiny、Small、Base+、Large，以及官方 SAM 1 ViT-H/L/B/T 按版本和架构简化显示；官方 `sam3.pt` 显示为 `SAM 3`；无法从文件名安全识别架构的用户自定义名称保留原文件名。只有能确定运行后端的 SAM 2/2.1 和 SAM 3 可启用画布开关与高级按钮。默认先恢复项目设置中的文件名，其次选择 `sam2.1_hiera_base_plus.pt`，最后选择首个模型。
- `高级`打开约 `480 x 400 px`、最小 `440 x 360 px` 的独立模态窗口；顶部“当前模型”改为可选模型下拉框，模型文件与标注形状下拉框的文本左边缘对齐，右侧提供`打开文件夹`按钮打开所选 checkpoint 的所在目录，取消窗口不会切换模型，保存后才同步模型选择。窗口其余内容分为“预测质量”和“结果处理”：快速单结果/三候选优选默认快速单结果；最低预测质量范围 `0.00~1.00`、默认 `0.00`；最小掩码面积使用与轮廓简化比例对齐的滑块和数值框，范围 `1~100000000 px²`、默认 `4`，滑块采用对数刻度；轮廓简化比例范围 `0.00%~1.50%`、默认 `0.20%`；三个参数的数值框均不显示上下箭头，仍可直接输入并与滑块联动。恢复默认只修改待保存值，取消不保存，保存后清除旧预览并让在途结果失效，但不重载模型或重新编码图片。
- 项目设置持久化 `annotation.sam_assist.model_path`、`multimask_output`、`minimum_score`、`minimum_area` 和 `polygon_simplification_ratio`，不持久化启用状态。程序启动、离开数据标注页、切换项目和退出程序时均保持或恢复为关闭；关闭开关时只停止预览和推理，继续保留已加载模型，直到离开数据标注页、切换项目或退出程序时才释放模型与显存。
- SAM 智能标注接管 `矩形框`、`有向矩形`、`镜像有向矩形` 和 `多边形`；开启时 `圆形` 和 `直线扩展` 在窗口与右键菜单中同步禁用，若当前处于不支持形状则自动切换为矩形框；`编辑` 始终可用。
- SAM 开启且当前为受支持形状时，普通点击、拖动和多边形逐点绘制全部停用。鼠标在图片内且未命中已有正式标注时，首个位置立即请求单正点分割，持续移动期间只保留最新坐标并按最近推理耗时在 `50~120 ms` 范围内自适应提交；同一形状下原图坐标变化小于 `2 px` 时跳过重复请求。不需要等待鼠标停止，也不允许请求在途时继续堆积。命中已有标注时清除预览且不发起推理。
- SAM 预览使用 LabelPaw 风格的纯绿色不透明边缘、约 `50` alpha 的绿色填充和固定屏幕像素虚线边框，实线段约 `12 px`、空隙约 `5 px`（窗口缩放不改变虚线长短、宽度或粗细），不显示控制点，不加入正式标注列表、撤销状态、脏状态或保存文件。左键只确认当前屏幕上仍可见的预览，不执行第二次推理；尚无有效预览时左键只请求或等待预览，不得回退到普通手工绘制。
- 预览确认后复用画布现有完成标注流程，使用当前类别并继续遵循连续标注、脏状态、自动保存和 Labelme/YOLO 转换设置。关闭连续标注时确认后回到编辑模式，但 SAM 开关继续保持开启，直至用户关闭或离开页面。
- 鼠标持续移动时保留最近完成的一帧预览，并按推理完成顺序连续替换；较新坐标仍在等待时允许显示同一模型、图片和形状下最近完成的结果。控制器最多保持一个在途推理和一个最新待处理坐标，推理完成后根据指数移动平均耗时安排下一次提交。切图、切模型、切形状、关闭开关、离开画布、命中已有标注、确认标注或进入编辑模式时立即清除预览并建立失效边界，边界之前的迟到结果不得恢复旧预览；关闭开关不终止 SAM 运行时，重新开启时复用已加载模型和图片编码。
- 没有模型时模型框显示不可用状态并禁用开关和高级按钮；SAM 2/2.1 与 SAM 3 可用于画布点提示预览，SAM 3 使用官方交互式单点预测器、必须具备 CUDA 且不回退 CPU；仅能识别为自定义名称但无法确定后端的模型仍显示在列表中，其开关和高级按钮保持禁用。模型加载或运行失败时清除预览、自动关闭开关、写入程序日志并显示一次明确错误。SAM 2/2.1 在 CUDA 不可用时允许回退 CPU，并在日志中提示悬停预览可能较慢。
- AI 预标注实际启动前必须关闭画布 SAM 开关并等待其隐藏子进程退出，释放模型和显存；AI 任务结束后不自动恢复画布 SAM。
- `圆形` 标注采用两次点击确认：第一次确定圆心，第二次确定半径。
- 数据标注页底部显示当前模式状态栏（如 `当前状态：编辑`、`当前状态：圆形`），默认开启；可在“更多设置”的“显示当前状态”中关闭。状态栏不叠加在画布内容上，离开数据标注页后自动隐藏。
- 数据标注页底部状态栏与左侧栏、画布、右侧栏的模块底边保持 `3 px` 间距。
- 关闭“显示当前状态”后隐藏状态栏，并恢复左侧栏、画布和右侧栏与软件底边原有的 `12 px` 留白。
- “更多设置”中提供 `开启连续标注` 开关，默认关闭；关闭时每次完成一个标注后自动回到 `编辑` 模式，开启后保持当前标注类型继续绘制。
- “更多设置”中提供 `开启快捷标注` 开关，默认关闭；开启时 `矩形框`、`圆形`、`直线扩展` 支持按住鼠标拖动后松开直接完成，关闭时改为通过多次点击确认。
- “更多设置”中提供 `开启直线扩展标注` 复选框开关，默认关闭；开启后标注类型选择中显示 `直线扩展`。
- “更多设置”中提供 `YOLO 标注文件夹` 编辑项，位于 `直线扩展像素` 上方；项目目录内显示为相对路径。
- “更多设置”窗口拉高时，各设置项之间的额外垂直空间应平均分配；`直线扩展像素`标题与数值框保持为同一组。
- “更多设置”窗口默认尺寸为 `300 x 450`。
- “更多设置”窗口底部按钮显示为 `确定` 和 `取消`。
- “更多设置”中提供 `显示标注名称` 开关，默认关闭；关闭时画布只显示标注图形，不显示对应的类别名称。
- “更多设置”中的 `自动转换为 YOLO 格式`、`显示标注名称` 和 `显示当前状态` 均显示 `ⓘ` 解释符号，并在悬停时显示对应 tooltip。
- `Esc` 规则：
  - 若当前正在绘制标注，先取消当前标注。
  - 若当前没有正在绘制，但仍处于某个绘制模式，再退回 `编辑` 模式。
- 若当前处于 `编辑` 模式且已选中标注，取消当前选中状态。
- 标注绘制过程中使用半透明纯绿色轮廓，不显示类别名称；该轮廓与图片背景混合，在纯白背景上显示为约 `rgb(127, 255, 127)`；仅多边形在已确定至少三个顶点后显示半透明纯绿色背景，在纯白背景上显示为约 `rgb(191, 255, 191)`，其他绘制类型仅显示绿色轮廓；标注完成后恢复对应类别颜色。
- 从 `编辑` 模式切换到任意绘制模式时，自动取消当前标注选中状态。
- 标注完成后默认不选中；如需编辑，用户可在编辑模式下点击标注框选中。
- 连续标注模式下，完成标注后下一次点击开始新标注时，应先取消上一标注的选中状态，同时保持连续绘制模式。
- 所有标注模式下，已完成标注的控制点常驻显示；绘制模式仅展示控制点，不允许选中或拖动。编辑模式下未选中标注显示圆点，鼠标接触标注框、内部或控制点时显示与选中态深度一致的背景，移开后恢复无背景；悬浮到具体控制点时仅该点显示为方块，并可直接拖动。选中标注继续显示同等深度的半透明背景，移开鼠标后控制点显示圆点。
- 鼠标悬停到可选中标注或控制点上时，光标应切换为小手样式。
- 除 `编辑` 模式外，选择任意绘制模式后，画布中的光标应显示十字样式；多边形悬停到可用于封闭图形的顶点时仍显示小手样式。
- 手动 `矩形框` 绘制模式下，鼠标所在位置额外显示贯穿画布的水平和垂直十字辅助线；SAM 智能标注开启时不显示该长十字辅助线，仅保留系统短十字光标。长十字依据鼠标热点下图片亮度在黑色与深灰色（`#000000` 至 `#484848`）之间变化，始终保持灰阶，不显示彩色，并在短十字光标热点周围留出采样空隙，使系统光标仍依据原始图片背景显示对比色；切换其他绘制模式或离开画布后清除辅助线，重新进入画布时立即恢复当前鼠标位置的辅助线与短十字光标。
- 控制点样式当前区分状态：绘制预览和已完成标注默认显示实心圆点；圆形标注绘制预览中的半径控制点随鼠标相对圆心的方向沿圆周移动，完成后固定使用标注时写入 JSON 的半径点位置，绘制模式只展示该位置、不开放交互；编辑模式鼠标悬浮到某个控制点时，该点显示实心方块，其余控制点显示空心圆点，移开鼠标后恢复实心圆点。用户可拖动控制点或直接拖动整个已选中标注。
- 控制点尺寸固定：默认实心控制点半径 `3.5 px`（直径 `7 px`），悬浮状态的空心圆点和方块半径 `4.5 px`（直径 `9 px`），不随图片分辨率变化；编辑模式控制点命中范围按最大可视半径的 `2.0` 倍计算。
- 除多边形外，绘制过程中的预览图形使用半透明纯绿色实线，预览控制点使用不透明纯绿色实心圆点；有向矩形、镜像有向矩形、直线扩展在未完成前的起始预览线也使用该绿色实线。
- 多边形绘制过程中需显示所有已确认顶点，并在至少三个顶点确定后显示半透明纯绿色背景；鼠标悬停到可用于封闭图形的顶点上时，光标切换为小手样式，点击该顶点后立即封闭图形，并短暂显示对应类别颜色的半透明填充作为完成反馈。
- 标注列表显示格式为：`序号.类别-绘制类型（最终格式）`，例如 `1.weld-镜像有向矩形（obb）`。
- 图片列表标题显示为 `图片列表`，右侧显示当前索引/总数，例如 `15/460`。
- 图片列表中每个文件名前显示与 `AI预标注 -> 自定义图片列表` 一致的只读 `QCheckBox` 勾选状态；有标注时勾选，无标注时不勾选。
- 首次进入数据标注页时，页面构造阶段不应立即同步执行整套图片扫描；应在页面首次显示后再启动首轮扫描，让导航切页先完成、页面先变为可交互，再尽快显示当前图片与首批图片列表项。
- 若主窗口已在空闲阶段预热过标注页，则切到标注页时应尽量直接显示第一张图片，避免先看到空画布再闪出首图。
- 切换大图片目录时，页面应优先可交互并尽快显示当前图片与首批图片列表项；其余图片列表项和勾选状态允许后台分批补齐，不得因一次性扫描全部图片与标注而出现明显卡顿。图片列表实现应避免为大量不可见行同步创建真实 `QCheckBox` 子控件。
- 若预热阶段已先渲染首批图片列表项，后续分批补齐与后台标注状态扫描仍必须继续执行，不能停留在首批 20 项。
- 图片列表项若使用行内自定义控件显示勾选框和文件名，则底层 `QListWidgetItem` 本身不应再额外绘制同一份文件名文本，避免出现文件名重影或序号错位。
- 图片列表中的勾选框属于只读状态展示，不用于直接点击切换；视觉上应保持正常启用样式，不应呈现禁用发灰效果。
- 管理类别窗口中的类别列表显示格式为：`0 : weld`。
- 顶部中间不再显示图片路径、标签路径等长路径文本。
- 顶部主导航按钮当前采用仅文字样式，不额外显示各页面图标；字号应略大于默认值，保证在 Windows 桌面环境下清晰易读。
- 左侧工具栏标题上方不再显示单独图形符号。
- 左侧标题 `数据标注` 后显示 `ⓘ`，tooltip 说明当前可通过右键菜单快速切换标注类型，默认读写 Labelme，并可在“更多设置”中开启 YOLO 文件保存。
- 主画布右键菜单顶部当前为 `编辑`，随后是分隔线和各标注形状；菜单底部在其他操作项之后再显示分隔线和带动画开关的 `SAM 智能标注`。SAM 行使用普通自定义菜单行样式；右键菜单只切换启用状态，模型仍在“画标注框”窗口中选择；两处开关状态实时同步。
- 当右键命中某个已选中标注时，主画布右键菜单应额外显示 `标注类别` 子菜单，并允许直接切换该标注的类别。
- 主画布右键菜单底部功能项当前约定：
  - 若“更多设置”中的 `右键显示保存YOLO标注` 关闭，且 `自动保存 Labelme JSON` 关闭，则显示单个 `保存`，默认保存 Labelme 标注。
  - 若 `右键显示保存YOLO标注` 开启，则按需分别显示 `保存Labelme标注` 与 `保存YOLO标注`；对应自动保存已开启的项目不再显示。
  - `保存` / `保存Labelme标注` 显示快捷键 `Ctrl+S`。
  - `删除` 仅在当前已有选中标注时显示，并显示快捷键 `Del`。
  - `撤销` 仅在当前图片存在未保存修改时显示，并显示快捷键 `Ctrl+Z`。
  - `取消当前绘制` 仅在当前确实存在未完成的临时绘制内容时显示，并显示快捷键 `Esc`；仅选择了某个绘制形状但尚未开始绘制时不显示。
- 主画布右键菜单中 `删除` 采用原生 `QAction` 样式，保证与其他原生菜单项对齐且快捷键列显示一致。
- 数据标注页当前内置可用的 `AI预标注` 弹窗，不再是占位按钮。
- AI 预标注弹窗当前默认大小为 `700 x 620`，最小大小为 `650 x 520`。
- AI 预标注弹窗顶部采用左右两张卡片布局：左侧为“模型与参数”，第一行放模型文件；普通 YOLO 模型显示第二行 `置信度` 与 `IoU`，右侧为“范围与模式”，包含“标注范围”下拉框与“追加 / 替换”处理模式。
- AI 预标注顶部“范围与模式”卡片中的标题、标注范围和处理模式应保持顶部紧凑排列；窗口额外高度留在卡片底部，不在两行控件之间均匀拉开空隙。
- AI 预标注支持：`当前图片`、`当前及以后图片`、`全部未标注图片`、`全部图片`、`自定义图片` 五种范围；支持 `追加` 与 `替换` 两种处理模式；支持模型类别到当前项目类别的映射；推理结果先直接转换为页面内部标注对象并写回 Labelme `.json`，并可按设置同步写 YOLO `.txt`，不是先生成 YOLO 再反转为 Labelme。
- AI 预标注选择 `当前图片` 时，只允许处理当前图片；不得错误扩展到全部图片。
- AI 预标注执行与模型类别读取都应通过隐藏子进程完成；同一次 AI 预标注窗口会话内应尽量复用同一个后台子进程，避免仅因先读取模型类别就重复加载 `torch`，并在关闭对话框、点击返回或中途停止后安全回收；这些操作都不得导致主窗口退出。
- AI 预标注选择 `自定义图片` 后，右侧计数区切换为 `列表` 按钮；非自定义范围显示 `已选择 x 张图片`。点击 `列表` 后打开图片选择窗口，显示当前图片文件夹内全部图片，文件名前带 `QCheckBox` 勾选状态；列表支持按文件名搜索，并在下方提供 `全选`、`反选`、`全不选` 等批量选择按钮，左下角显示 `已选择 x 张图片`，最终仅处理已勾选图片。
- 自定义图片列表支持按住鼠标左键拖动连续多选/取消；拖到列表上下边缘时会自动滚动，且越靠近边缘滚动越快。
- AI 预标注窗口关闭、返回或右上角关闭后，应持久化当前模型、置信度、IoU、标注范围、处理模式和自定义图片选择，下次打开时恢复。
- AI 预标注的“类别映射”表格必须在窗口缩小时保持可滚动和可选择，不能出现下半部分被裁掉、后续类别无法点击的情况；“标注类别”列中的下拉框文字不得被行高裁切。
- 选择项目或程序根目录 `data/models/sam3.pt` 时自动进入 SAM 3 文本分割模式；项目目录中的同名权重优先。SAM 3.1 视频 checkpoint、SAM 2/2.1 checkpoint 只保留画布辅助标注用途，不进入批量文本预标注。
- AI 预标注模型下拉框中，SAM 3 checkpoint 仅显示文件名 `sam3.pt`，完整路径保留在内部映射中用于执行和设置保存。
- SAM 3 模式将类别映射表替换为“启用 / 项目类别 / 文本提示词 / 状态”，默认启用全部项目类别并以类别名作为提示词；文本提示词表格行高为 `38 px`，编辑框所在单元格上下左右均保留 `5 px` 内边距，编辑框自身使用 `0` 内边距并保持至少 `28 px` 高，保证文字在表格行内完整显示；至少需要一条已启用且非空的提示词，未启用类别不会参与推理，也不会创建新类别。识别到 SAM 3 模型时隐藏普通置信度与 IoU 控件；“高级参数”按钮与标注形状选择位于同一行右侧，展开后显示最小 mask 面积与轮廓简化比例。
- SAM 3 模式提供 `矩形框`、`有向矩形`、`多边形` 三种输出形状。首次使用时 detect 项目默认矩形框，OBB 项目默认有向矩形；参数独立保存：置信度默认 `0.50`、跨类别 mask 去重 IoU 默认 `0.80`，高级参数为最小 mask 面积 `4 px` 与轮廓简化比例 `0.2%`。
- 每张图片只计算一次视觉特征，再按提示词收集候选并按分数稳定执行 mask IoU 去重。过滤小面积后取最大外轮廓：矩形框写 `rect`，有向矩形写 `obb`，多边形写 `polygon`；detect 的 YOLO 同步输出为轴对齐框，OBB 输出最小面积旋转框。
- SAM 3 仅支持 CUDA；无 CUDA、权重不兼容或显存不足时在写入文件前报告明确错误，不回退 CPU。运行前快照全部目标 Labelme/YOLO 文件，成功、停止或失败后均可使用“删除 AI 标注”恢复本轮之前状态。
- 类别映射表中鼠标指向“标注类别”下拉框滚动时，不切换下拉选项，滚轮继续驱动映射表滚动。
- 标注列表支持右键菜单：
  - 顶部显示 `标注类型`，点击后展开类别子菜单，作用与主画布右键中的 `标注类别` 相同。
  - 下方显示 `删除标注`，用于删除当前列表项对应的标注。
- 图片列表支持右键菜单：
  - 保存项遵循主画布右键菜单相同规则：显示 `保存` 或按需显示 `保存Labelme标注` / `保存YOLO标注`。
  - 其余操作包含 `删除所有标注`、`删除图片及标注`，两项采用红色危险操作样式。
- 当 `自动保存 Labelme JSON` 关闭且当前图片存在未保存标注修改时，右下角图片列表中文件名后方应显示红色 `（未保存）` 字样。
- 标注页快捷键当前约定：
  - `W`：打开标注类型选择窗口（与左侧 `画标注框(W)` 按钮相同）
  - `V`：编辑
  - `R`：矩形框
  - `O`：有向矩形
  - `M`：镜像有向矩形
  - `P`：多边形
  - `C`：圆形
  - `L`：直线扩展（仅在“更多设置”启用后生效）
  - `A`：上一张
  - `D`：下一张
  - `Del`：删除当前选中标注
  - `Ctrl+S`：保存当前 Labelme 标注
  - `Ctrl+Shift+S`：保存当前 YOLO 标注
- SAM 开启时忽略 `C/L`，`V/R/O/M/P` 保持有效；`V` 进入编辑模式后继续保持 SAM 开关开启。

## 类别识别与项目同步

- 右侧栏使用“任务类别”选择 `detect` 或 `obb`，使用“目标类型”选择当前类别。
- 未选中标注时，“目标类型”表示新建标注默认使用的类别；选中标注或列表项后立即切换到该标注类别。
- 选中标注时修改“目标类型”会立即修改该标注的类别并刷新列表；未选中标注时只修改后续新建标注的默认类别。
- 类别名称保存于当前项目的 `data/runtime/settings.json`。切换项目后重新读取项目类别，不沿用上一个项目的类别。
- 进入标注页或扫描项目图片时，读取 Labelme 标注目录下所有 JSON 的非空 `label`；设置文件中不存在的类别按扫描顺序追加并保存。

## OBB 编辑补充

- 编辑模式下，有向矩形在四条边的中心各显示一个圆形旋转控制点；拖动时围绕四角点几何中心旋转，不改变矩形中心、长宽和四角点顺序。
- 有向矩形四个角点仍用于调整尺寸和方向；整体拖动时旋转控制点与角点同步移动。旋转控制点只在编辑模式下可命中和拖动，绘制预览仅显示控制点。
- 镜像有向矩形默认使用普通有向矩形控制点；开启“优化镜像有向矩形编辑”后，编辑态显示中心线，并仅显示中心线两端和两条长边中心控制点。
- Labelme 文件中的镜像有向矩形和直线扩展保持 `shape_type: oriented_rectangle`，并通过 `flags.yolo_tool_shape` 保存 YOLOTool 内部形状；不带该标记的外部 `oriented_rectangle` 按普通有向矩形加载。

## 类别管理

- “管理类别”支持新增、重命名和删除类别。
- 重命名类别保持类别索引不变，已有标注继续引用原类别。
- 删除类别前统计当前项目标注中依赖该类别的数量；数量不为零时阻止删除并提示依赖数量。
- 类别管理窗口底部提供“转换类别”按钮，可将当前项目中所有标注的源类别改为目标类别；取消则不执行转换。
