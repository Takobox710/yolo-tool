# 系统设置规格

## 系统状态

系统设置页显示 Python、Torch/CUDA、Ultralytics、OpenCV、Pillow、ONNX、TensorRT 和程序版本；不单独显示 PySide6，也不在此处显示 GPU、显存、CPU、内存和磁盘状态。依赖版本优先读取发行版元数据，冻结包缺少 `.dist-info` 时回退读取模块自身的 `__version__`，不能只显示“已安装”。

程序版本来自源码内的 `APP_VERSION`。冻结态缺少发布清单或环境清单，或运行环境与程序要求不一致时，程序启动会拒绝运行并提示使用匹配的本体环境和模型包修复；这些兼容状态不在系统设置页单独展示。

## Windows 安装与更新

- 小型 `YOLOTool_Setup_<版本>.exe` 统一负责首次安装、程序升级、修复和确认后的降级，并允许选择新目录并行安装。默认目录为 `YOLOTool`，已有或非空目录不弹额外警告。
- 首次安装、基础环境缺失或版本不兼容时，必须同时提供匹配的本体环境和模型 `.7z`；已有兼容环境时默认只更新程序。
- 模型转换附加环境始终可选。系统设置页支持点击选择或拖入附加包，安装到当前程序目录 `_internal/extensions/model-export-runtime/`；旧版本位于 `%LOCALAPPDATA%/YOLOTool/` 时自动迁移。
- 安装器组件页只快速检查 `YOLOTool_BaseEnv_<版本>.7z` 和 `YOLOTool_ExtraEnv_<版本>.7z` 的名称与大小，点击安装后再执行完整 SHA-256；软件内附加包安装优先由基础包携带的原生 7-Zip 完成并使用 CRC，安装清单隐藏在 `_internal/yolotool_metadata/`。

安装和更新不覆盖项目设置、最近项目状态、用户模型、图片、标签和训练结果。卸载仅删除受管官方模型，并保留上述用户数据。

## 页面布局与通用设置

- 系统信息区域位于页面最上方，使用白色外框和灰色内卡样式，按网格排列并定时刷新。
- 系统设置下方文本区域显示程序日志，不重复承载训练、验证、AI 预标注、数据集划分、模型格式转换和图片压缩页面各自的专属日志。
- 路径设置中，数据集划分、标注预览、批量重命名和数据标注共用图片目录；数据标注、数据集划分和批量重命名共用 Labelme 标注目录；标注预览和数据集划分共用 YOLO 标注目录；图片压缩源目录独立保存。
- 系统信息下方同一行提供 `训练前显示自定义命令框`、`显示配置解释符号`、`模型验证显示 last`、`多类别分布模式` 和 `恢复默认设置`。

## 设置文件兼容与维护模型

- 当前项目设置保存于项目目录 `data/runtime/settings.json`，应用级最近项目状态保存于应用根目录 `data/runtime/app_state.json`。
- 设置文件使用 `schema_version: 1`。无版本文件按 v0 迁移，已有字段名、默认值、相对路径存储、外部绝对路径和裸模型名解析规则保持不变。
- 运行时设置由嵌套 `slots=True` dataclass `AppSettings` 表示，页面通过 `WorkbenchContext` 访问 `settings.training.epochs` 等属性，不直接操作任意嵌套字典。
- `SettingsService.load()` 返回设置、迁移标记和问题列表。非法字段只回退该字段，未知字段忽略并报告；损坏 JSON 或需要纠正原文件时先生成一次备份。
- `SettingsService.save()` 只接受 `AppSettings`，保存前再次校验；恢复默认设置保留当前项目根目录。
- 页面设置变更由 `WorkbenchContext.save_settings()` 比较快照后持久化，并只广播实际变化字段；项目切换时递增 generation，使旧页面的后台结果失效。

## 设置项行为

- `训练前显示自定义命令框` 控制训练页是否弹出命令编辑对话框。
- `显示配置解释符号` 只控制字段名后的 `ⓘ` 是否显示；关闭后仍保留字段名称自身的 Qt tooltip。
- `模型验证显示 last` 控制模型验证页是否显示训练结果中的 `last.pt`，默认关闭时只显示 `best.pt`。
- `恢复默认设置` 将当前项目设置恢复到代码默认值，但保留当前项目目录不变。
- 系统设置页不提供常驻的“自动加载 torch”预热开关；Torch/CUDA 环境信息通过短生命周期后台子进程读取，完成后立即退出。
