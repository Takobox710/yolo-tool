# 系统设置规格

## 系统状态

系统设置页显示 Python、Torch/CUDA、GPU、显存、CPU、内存、磁盘和依赖模块版本；依赖卡片顺序为 Ultralytics、OpenCV、Pillow、ONNX、TensorRT，TensorRT 后接程序版本，不单独显示 PySide6。依赖版本优先读取发行版元数据，冻结包缺少 `.dist-info` 时回退读取模块自身的 `__version__`，不能只显示“已安装”。

程序版本来自源码内的 `APP_VERSION`。冻结态缺少发布清单或环境清单，或运行环境与程序要求不一致时，程序启动会拒绝运行并提示使用匹配的本体环境和模型包修复；这些兼容状态不在系统设置页单独展示。

## Windows 安装与更新

- 小型 `YOLOTool_Setup_<版本>.exe` 统一负责首次安装、程序升级、修复和确认后的降级，并允许选择新目录并行安装。默认目录为 `YOLOTool`，已有或非空目录不弹额外警告。
- 首次安装、基础环境缺失或版本不兼容时，必须同时提供匹配的本体环境和模型 `.7z`；已有兼容环境时默认只更新程序。
- 模型转换附加环境始终可选。系统设置页支持点击选择或拖入附加包，安装位置按当前安装实例隔离。
- 安装器组件页只快速检查 `YOLOTool_BaseEnv_<版本>.7z` 和 `YOLOTool_ExtraEnv_<版本>.7z` 的名称与大小，点击安装后再执行完整 SHA-256；软件内附加包安装优先由基础包携带的原生 7-Zip 完成并使用 CRC，安装清单隐藏在 `_internal/yolotool_metadata/`。

安装和更新不覆盖项目设置、最近项目状态、用户模型、图片、标签和训练结果。卸载仅删除受管官方模型，并保留上述用户数据。
